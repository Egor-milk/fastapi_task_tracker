Временные файлы фронтенда находятся в src/ и имеют префикс frontend-*. 
Переместите их в отдельную папку frontend/ при желании.

Как запустить:
1) Перейдите в директорию проекта и создайте папку frontend/ локально.
2) Скопируйте файлы с префиксом frontend-* в новую папку, сохранив структуру src/
   (index.html, package.json, src/main.jsx, src/App.jsx, src/components/...)
3) Внутри frontend/ выполнить npm install и npm run dev

Если нужен — могу создать корректную структуру frontend/ в репозитории, 
но окружение выполнения инструментов сейчас не позволяет создать новые каталоги. 
Поэтому файлы созданы временно в src/.
